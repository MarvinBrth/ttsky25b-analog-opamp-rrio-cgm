# SKY130 rail-to-rail op amp

Self-biased 3.3 V class-AB OpAmp for Tiny Tapeout SKY 26d, using 1x2 tiles and three analog pins.

See [the project documentation](docs/info.md) for connections and testing. The current sources are the [Xschem schematic](xschem/opamp-rrio-cgm-3v3.sch) and [Magic layout](mag/tt_um_marvinbrth_opamp_rrio_cgm_3v3.mag). Set `PDK_ROOT` to your SKY130 PDK installation before opening them.
